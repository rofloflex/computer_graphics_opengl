# Лабораторная работа №4. 
Движение камеры, использование матриц. Работа с библиотекой glm.
## Описание
реализовано создание окна с использованием GLFW и GLAD, отрисовка 3D-куба средствами OpenGL, а также базовое управление камерой (перемещение с помощью клавиш WASD и обзор мышью) с применением матриц преобразований (model, view, projection).
